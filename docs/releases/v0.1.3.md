# PS7-Completion 0.1.3

Adds Windows ipconfig, tracert, nslookup and netstat, plus curl.exe, Cargo and
Docker with Compose subcommands. The framework now bundles 34 providers.

Menus retain command-first ordering. All new providers are static: completion
never runs diagnostics, resolves DNS, sends HTTP requests, reads credentials,
invokes Cargo or contacts a Docker daemon. Docker need not be installed for
registration. The curl provider registers only curl.exe to avoid shell aliases.

See the [complete provider reference](../providers.md) for supported syntax
subsets and the [origin notes](../provider-origins.md) for installation checks.
Restart PowerShell after upgrading an installed module. Private distribution
and the deferred public WinGet publication remain unchanged.
