# PS7-Completion 0.1.5

This normal private release improves import and completion performance, and adds
repeatable benchmarks. It retains the four-command public API and 34 bundled
providers.

- The installer now contains a build-assembled module. The SSH parser still loads
  only when needed. In a same-machine comparison, module import improved from
  159.20 ms to 90.67 ms p95; 4096-candidate result formatting improved from
  41.14 ms to 33.31 ms p95.
- Completion lookup now indexes provider ownership, normalizes SSH cache paths,
  and avoids repeated metadata reads within a bounded SSH parse. Link-target
  changes invalidate SSH cache entries.
- Process, service and task queries retain the disposable worker and 500 ms work
  deadline. Process handles are disposed and task-folder traversal is bounded.
- Benchmarks cover all 34 providers, Python script and pip routing, first/warm
  completions, cache hits/misses, worker timing and large result sets. CI retains
  JSON reports. Same-machine comparisons can enforce timing limits without using
  shared-runner timing as a release gate.

See the [performance plan](../performance-plan.md) and [changelog](../../CHANGELOG.md)
for the protocol, results and changes. System lookup gains were mixed; worker
startup remains the main uncached cost. The measurement is a sample from one
Windows machine, not a timing guarantee for other installations.

Install the Windows x64 EXE, then start a new PowerShell 7.4+ session. Verify the
unsigned installer against SHA256SUMS.txt. The repository remains private and
the generated WinGet manifest is preparation for future public distribution;
it does not make the package publicly installable through WinGet.
