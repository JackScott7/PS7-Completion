# PS7-Completion 0.1.4

This normal (non-prerelease) patch delivers Python script routing and installer-only
distribution. It retains the 34 bundled providers and four-command public API;
it does not declare completion of the v0.5 or v1.0 roadmap.

- Register `mom.py` once to complete both `mom.py ...` and `python mom.py ...`.
  Providers receive script-relative arguments while retaining the original AST
  and absolute cursor. Quoted paths and supported interpreter switches work.
- `python -m pip` and `pip` share the registered provider, including replacements,
  exclusions, lazy loading, argument context and failure isolation.
- Distribute the Windows x64 Inno Setup installer, SHA256 checksums and generated
  WinGet metadata. No module ZIP is produced. WinGet metadata targets the same EXE.
- Snapshot shell aliases once during bundled-provider validation at import.
- Release automation tests the exact installer, compares installed payload hashes,
  validates both supported PowerShell baselines and verifies downloaded asset hashes
  before publishing a tag-triggered release. Manual workflow runs remain drafts.

Run the installer to upgrade, then open a fresh PowerShell 7.4+ session. Add
`Import-Module PS7-Completion` to your profile if it is not already present.
Installation does not install PowerShell, edit profiles or change search paths.
The installer is unsigned; verify it against SHA256SUMS.txt.

The repository remains private. Public WinGet publication is deferred, and a
generated manifest does not make private GitHub download URLs publicly installable.
Public WinGet validation and end-to-end package-manager installation remain release
gates for that channel. See [release evidence](../release-status.md) for results
and remaining performance/installer certification limits.
