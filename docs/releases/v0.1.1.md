# PS7-Completion 0.1.1

This private patch release fixes SSH host completion for local symbolic links and
junctions, including linked `.ssh` directories. It also reads SSH config in the
current PowerShell session, removing the extra process startup from the first
completion request.

On the development machine, seven fresh-shell `ssh s` measurements improved from
735 ms median to 152 ms median. Results depend on the machine and SSH config.

The installer includes the same module files as the ZIP. Existing users can run
the new installer to upgrade, then open a new PowerShell 7 shell and import
`PS7-Completion`. Existing profiles that already import the module need no edit.

The Windows x64 installer is unsigned. Verify the downloaded ZIP and EXE using
the release's `SHA256SUMS.txt` before installation. This private release is not
available through WinGet.
