# PS7-Completion 0.1.2

This private release expands the framework from 5 to 27 built-in providers.
The original Windows/OpenSSH providers are joined by Git, GitHub CLI, ripgrep,
jq, Python/pip, uv/uvx, Uvicorn, Twine, Ruff, Flask, FastAPI, Tailscale, Node/npm,
SQLite, FFmpeg, rustc/rustup, nano, and Windows ping.

Completion menus now list commands/subcommands before options and arguments,
with alphabetical ordering within each group. Python's `-m pip` form delegates
to the pip syntax provider. Providers remain lazy and never execute the tool
being completed. Syntax support is deliberately bounded: see the
[provider reference](../providers.md) and [installation identification](../provider-origins.md).

The source manifest and build payload version are 0.1.2. Restart PowerShell after
upgrading an installed module. This change does not publish a public WinGet
package; private distribution remains unchanged.
